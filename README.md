# techcareerfit-backend

FastAPI backend for TechCareerFit ATS Compatibility and Career Development Platform.

## Available API Endpoints

The project currently exposes the following routes:

- `GET /` — API root status
- `GET /auth/` — Authentication module status
- `GET /users/` — Users endpoint status
- `GET /cv/` — CV endpoint status
- `GET /ats/` — ATS engine endpoint status
- `GET /jobs/` — Jobs endpoint status
- `GET /reports/` — Reports endpoint status
